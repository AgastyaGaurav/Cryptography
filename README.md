Cryptography is the science of securing information by transforming it into a form that unauthorized people cannot understand, while allowing authorized users to access it.

In simple terms, cryptography helps protect data from being read, modified, or forged by others.

Goals of Cryptography
Confidentiality
  Ensures that only authorized users can read the information.
  Example: Encrypting messages in a chat application.
Integrity
  Ensures that data has not been altered during transmission or storage.
  Example: Using hash functions to verify file integrity.
Authentication
  Verifies the identity of the sender or receiver.
  Example: Passwords, digital certificates.
Non-repudiation
  Prevents someone from denying that they sent a message or performed an action.
  Example: Digital signatures.
  
Basic Process

Plaintext → Encryption → Ciphertext → Decryption → Plaintext

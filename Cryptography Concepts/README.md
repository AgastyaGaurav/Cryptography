# Python Cryptography Algorithms

A comprehensive collection of cryptographic algorithms implemented in Python for educational purposes, security research, and algorithmic learning. This repository provides clean, well-documented implementations of classical and modern cryptographic techniques, allowing users to understand the mathematical foundations and practical applications of encryption, decryption, hashing, and secure communication.

## Features

* Classical Ciphers

  * Caesar Cipher
  * ROT13 Cipher
  * Vigenère Cipher
  * Playfair Cipher
  * Rail Fence Cipher
  * Hill Cipher
  * Affine Cipher
  * Transposition Ciphers

* Modern Cryptography

  * AES (Advanced Encryption Standard)
  * DES (Data Encryption Standard)
  * Triple DES (3DES)
  * RSA Encryption
  * Diffie-Hellman Key Exchange
  * ElGamal Encryption

* Hashing Algorithms

  * MD5
  * SHA-1
  * SHA-256
  * SHA-512

* Message Authentication

  * HMAC Implementation
  * Digital Signatures

* Utility Functions

  * Key Generation
  * Random Number Generation
  * File Encryption and Decryption
  * Text-Based Encryption Tools

## Objectives

This project aims to provide beginner-friendly and intermediate-level implementations of cryptographic algorithms using pure Python. Each algorithm includes explanations, source code, examples, and comments to help learners understand how cryptography works under the hood.

## Educational Purpose

The implementations are designed primarily for learning and experimentation. They demonstrate encryption principles, key management, data integrity verification, and secure communication concepts. While some algorithms are suitable for practical applications, users should rely on established cryptographic libraries for production environments.

## Technologies Used

* Python 3.x
* Standard Python Libraries
* Cryptographic Libraries (where applicable)
* Object-Oriented Programming Concepts
